# Historias de usuario candidatas

Estado común: `IDENTIFIED`; son candidatas del inventario, sin criterios de aceptación. «Primaria» y «secundaria» designan las cuentas sintéticas de `roles.md`. Los permisos se refieren al recurso indicado, no a privilegios globales. El contexto distingue controles visibles de operaciones ejecutadas.
